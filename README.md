# MARZOOK 家具搭配工作室

网站包含486件家具素材、9套区域搭配、当前首层图纸与空间预览。

- 首页：按款式、颜色和类别选款，查看原图对照。
- 区域 Moodboard：从五个区域选择方案，切换自由搭配后拖入家具；单品可以移动、缩放、旋转、镜像及调整前后层。
- “本次新增灯饰”可查看26组新增素材。
- 方案自动保存在当前浏览器；使用“备份方案”下载JSON，可通过“导入方案”继续编辑。
- 方案成图可下载，自由画板可导出高清图片；图纸和空间模式沿用现有项目资料。

产品素材采用无损WebP编码，解码RGBA像素与原PNG逐字节一致。

新增21件优先3D照片重建：在 models.html 中环视、对照最新原图、下载内嵌贴图GLB，或直接放入空间。模型为试摆重建，尺寸与隐藏细节待实测，非厂家生产CAD。沿用原有家具编号，未新增重复商品。

餐区、圆厅与柱位客厅新增宽幅空景，依据图纸和多角度现场复原；保留此前视角与旧方案。可下载三张宽景整包及21件模型整包。

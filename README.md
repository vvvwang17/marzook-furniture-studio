# MARZOOK 家具搭配工作室

网站包含506件家具素材、9套区域搭配、当前首层图纸与空间预览。

- 首页：按款式、颜色和类别选款，查看原图对照。
- 区域 Moodboard：从五个区域选择方案，切换自由搭配后拖入家具；单品可以移动、缩放、旋转、镜像及调整前后层。
- “本次新增灯饰”可查看26组新增素材。
- 方案自动保存在当前浏览器；使用“备份方案”下载JSON，可通过“导入方案”继续编辑。
- 方案成图可下载，自由画板可导出高清图片；图纸和空间模式沿用现有项目资料。

产品素材采用无损WebP编码，解码RGBA像素与原PNG逐字节一致。

优先三维清单现有41款（制作状态以页面标记为准）：在 models.html 中环视、对照最新原图、下载内嵌贴图GLB，或直接放入空间。模型为试摆重建，尺寸与隐藏细节待实测，非厂家生产CAD。沿用原有家具编号，未新增重复商品。

餐区、圆厅与柱位客厅新增宽幅空景，依据图纸和多角度现场复原；保留此前视角与旧方案。可下载三张宽景整包及首批21件模型整包；咖啡桌新组合可单独下载。

新增 `vr.html` 客户空间 VR：沿用当前 SU / CAD 与现场修正版的连续建筑网格，支持入口及五区切换、电脑和触屏行走、立体总览、平面定位、原图对照、日间/暖光和2400像素宽视角导出。支持设备可进入 WebXR 头显模式，使用控制器传送与30°分段转身；网页漫游已验证，头显追踪与双眼画面仍待实体设备测试。

VR 可读取当前浏览器的三维家具方案或导入原工作室 JSON，只读显示而不覆盖原方案。下载 `space-assets/client-space.glb` 可获得478个建筑网格、41996个三角面和7张内嵌原贴图的米制模型。保留餐区+275mm地台与三柱；局部梁窗/吊顶/柱尺寸仍为待复核值。未经可靠定位的独立电视/餐区未并入。
